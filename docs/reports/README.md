## 큰 그림

01번 커밋에서 편집 화면을 완전히 새로 설계(원본 이미지 위에 코드를 직접 탭/드래그로 편집)한 뒤, 02~05번에서 그 위에 라이브러리 퍼시스턴스 · PDF 그룹화 · 곡 메타데이터(BPM/메모/섹션 라벨) · 송폼(셋리스트) 기능을 순서대로 얹었습니다. 06~08번은 그 과정에서 실사용 중 발견된 버그 3건(스캔 멈춤, 저장 용량 초과, 브라우저별 이미지 표시 실패)을 원인부터 추적해 고친 기록입니다. 09번은 별도로 전달받은 디자인 목업에서 스타일 값만 뽑아 향후 리스타일링에 쓸 수 있는 토큰 모듈을 만든 작업입니다.

현재 남아있는 항목: 커뮤니티 공유·웹 앱 연동(서버 필요, 보류 중), 다중 페이지 PDF의 PDF 일괄 내보내기, 디자인 토큰을 실제 화면에 적용하는 리스타일링.
