# 05. 송폼(셋리스트) 등록·수정·저장 기능 추가

- **커밋:** `2ab4fc5bb94260f88225f2bb28bfbd8dbb6f90fb`
- **날짜:** 2026-09-09

## 배경 / 문제

요청 기능 목록의 C) "송폼 등록 및 수정 + 곡별 셋 저장 및 다시 불러오기" — 사실상 같은 기능(순서가 있는 곡 목록을 저장하고 나중에 재사용)이라 하나로 묶어 구현.

## 변경 내용

- 새 `src/features/setlist/` 기능 모듈: `Setlist`는 `{ id, title, songIds, updatedAt }` — 라이브러리 곡을 id로만 참조하는 가벼운 구조. `AsyncStorage`에 라이브러리와 동일한 패턴으로 저장.
- 홈 화면에 **"내 악보" / "송폼" 탭 스위처** 추가.
- `SetlistListScreen`: 저장된 송폼 목록, 새로 만들기, 삭제.
- `SetlistEditorScreen`: 송폼 이름 수정, 곡 순서 변경(▲▼ 버튼), 곡 제거(확인 모달 — 라이브러리에서는 삭제 안 됨), `SongPickerModal`로 라이브러리에서 곡 추가.
- 라이브러리 화면의 PDF 그룹화 로직(`groupSongs`)을 `src/features/library/groupSongs.ts`로 분리해 송폼의 곡 선택 목록에서도 재사용.
- 송폼에서 곡을 탭하면 바로 편집 화면으로 이동하고, 완료하면 **원래 보고 있던 송폼으로 복귀**하도록 설계(라이브러리에서 직접 연 곡은 라이브러리 홈으로 복귀) — `openFromLibrary`와 `openSongFromSetlist`를 분리해 "어디서 열었는지"에 따라 돌아갈 곳이 달라지는 상태 혼선을 방지.

## 검증

- 타입체크·전체 테스트(75개) 통과.
- 웹 빌드에서 라이브러리 → 송폼 탭 전환 → 새 송폼 만들기 → 곡 추가 모달까지 Playwright로 직접 클릭해 에러 없이 동작 확인.
