# 08. Safari(WebKit)에서 악보 이미지가 안 보이는 버그 수정

- **커밋:** `e50725f4f6db395a73bffccca43da44b6bd9919b`
- **날짜:** 2026-09-09

## 배경 / 문제

07번 수정 이후 사용자 리포트: "스캔했는데 텍스트는 나오는데 악보가 안나옵니다" — 코드 배지(텍스트)는 정상 표시되지만 원본 악보 이미지 자체가 안 보임.

## 원인

코드 배지는 저장된 좌표만으로 그려지므로 이미지 로드 성공 여부와 무관하게 항상 보인다 — 즉 이미지만 조용히 로드 실패했다는 뜻. `resolveWebImageUri`에 두 가지 문제가 있었다:

1. IndexedDB에 **Blob 객체를 직접 저장**하고 있었는데, 일부 브라우저(특히 Safari)는 structured clone으로 Blob을 저장/복원하는 데 알려진 버그가 있어 값이 손상되거나 읽기 실패할 수 있음 — 이때 아무 에러도 표면화되지 않음.
2. 복원 실패 시 함수가 **원래의 `wba-idb://` 참조 문자열을 그대로 반환**했는데, 이는 어떤 브라우저도 로드할 수 없는 값이라 `<Image>`에 그대로 전달되면서 조용히 렌더링 실패.

## 변경 내용

- IndexedDB 저장 형식을 Blob 대신 `{ buffer: ArrayBuffer, type }`로 변경 — 읽을 때 `new Blob([buffer], { type })`로 재구성. 이 경로는 Safari의 Blob 복원 버그를 우회한다.
- `resolveWebImageUri`가 복원 실패 시 **`null`을 반환**하도록 변경. `SourceOverlayScreen`은 이미 "아직 해석 중"과 동일하게 처리해 `<Image>`에 유효하지 않은 값을 전달하지 않음.

## 검증

- 타입체크·전체 테스트 통과.
- Playwright의 **Chromium과 WebKit(Safari 엔진) 양쪽**에서 스캔 → 즉시 표시 → 페이지 리로드 → 재표시까지 전 과정을 직접 구동해 이미지가 정상적으로 보이는 것을 스크린샷으로 확인.
